# Введение

## Что такое Plenka?

Домашняя система «смотреть фильмы с торрентов», рассчитанная на запуск контейнером на
роутере MikroTik. Состоит из трёх частей:

- **`backend/` — plenka-server**, один Go-бинарник: стриминг торрентов по HTTP, поиск
  по торрент-трекерам (собственный движок YAML-определений Cardigann, которые он скачивает
  из Jackett), прокси каталога TMDB и общая история просмотров. В него же встроено
  веб-приложение, поэтому роутер отдаёт всё с одного порта (8095).
- **`frontend/`** — веб-приложение на Vue 3, которое выглядит и ведёт себя как мобильное:
  каталог, поиск, выбор раздачи, плеер и экраны управления (торренты, трекеры, настройки
  движка).
- **`app/`** — клиент на Flutter (Android-телефоны и ТВ-приставки, Linux) с теми же
  сценариями и нативным плеером (libmpv); сервер в локальной сети он находит сам.

## Как устроен просмотр

1. Выбираете фильм в каталоге TMDB (или ищете сразу по трекерам).
2. Сервер параллельно опрашивает включённые трекеры и возвращает объединённый список раздач.
3. Выбранная раздача добавляется в торрент-движок; список файлов приходит от пиров.
4. Плеер читает файл из `/api/stream/...`, а движок докачивает нужные куски в кэш в памяти
   (или на диске). Позиция просмотра сохраняется на сервере, поэтому «Продолжить просмотр»
   общий для веб-приложения и мобильного.

## Границы

- Устройство для локальной сети: учётных записей и авторизации нет. Не открывайте порт
  8095 в интернет.
- Транскодирования нет: встроенный браузерный плеер играет то, что умеет браузер
  (MP4/H.264, WebM, часто HEVC в Safari/Android); остальное открывается во внешнем плеере
  (VLC, MX Player) по ссылке на поток или через плейлист M3U. Flutter-приложение играет
  почти всё.
- Клиенты — только встроенное веб-приложение и Flutter-приложение: API TorrServer и
  Jackett/Torznab сервер не поддерживает.
- Трекеры за проверкой Cloudflare (FlareSolverr) не поддерживаются.

## Лицензия

GPL-3.0 (`LICENSE` в корне репозитория). Торрент-движок основан на TorrServer MatriX
(GPL-3.0). Определений трекеров нет ни в репозитории, ни в бинарнике: сервер скачивает
определения Jackett (GPL-2.0) во время работы, а движок для них — независимая реализация
формата Cardigann.
